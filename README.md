# Universe — The Evolving Knowledge Cosmos

Public project introduction for **Universe**, an independent research and development initiative exploring relationships, evidence, and the evolution of understanding.

**Website:** https://martinwxi.github.io/universe-project/ (available after GitHub Pages is enabled)

**Contact:** https://github.com/martinwxi/universe-project/issues

## What Universe explores

- **Connections:** relationships between objects, events, systems, places, people, and ideas.
- **Evidence:** inspectable provenance and source context, rather than unexplained graph edges.
- **Time:** the difference between what was known at a point in time and what is understood in light of later evidence.
- **Review:** candidate interpretations and AI-generated hypotheses do not become published knowledge without appropriate review.

This repository contains **only the public introduction website**. It does not include the main application, internal documentation, research datasets, credentials, or a running knowledge service. The project is in a research and prototyping phase. No public verified knowledge dataset is advertised here.

**Important:** The presence of this example User-Agent does not mean that the client is currently running, or that external collection has been authorized. Universe is independent and is not affiliated with the Wikimedia Foundation or GitHub.

## Deploy with GitHub Pages

1. Upload the files in this website package into the **root** of the `main` branch. Keep the `assets/` directory intact. Do not upload the ZIP as a single file.
2. Visit [Repository Settings > Pages](https://github.com/martinwxi/universe-project/settings/pages).
3. Set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and the folder to `/ (root)`; select **Save**.
5. Once published, open https://martinwxi.github.io/universe-project/ and check the page, links and GitHub Issues contact route.
6. Only then use the public website as a User-Agent contact URL, subject to separate approval of any external network request.

This website is plain HTML/CSS/JavaScript and does not require a build, package manager, third-party fonts, analytics, external scripts, or a backend.
